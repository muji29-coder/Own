# shayan-fca

The Facebook Messenger library this bot uses to log in, receive and send messages.

Based on **fca-priyansh 18.0.0** (MIT license, see LICENSE), which is based on Fca-Horizon-Remastered and facebook-chat-api.

Changes from fca-priyansh 18.0.0:
- Name: shayan-fca, log name [ FCA-SHAYAN ], settings file ShayanFca.json
- Broadcast turned off (it downloaded messages from the old author's GitHub)
- The unused Dev_Horizon_Data function (sent user/group info to an outside server) turned off
- Dependencies pinned to the exact versions the bot already used
